# Roteiro final - Mainuan Gestao de Drivers 1.0

Executar em VM/snapshots descartaveis ou hardware elegivel com autorizacao.
Nenhuma instalacao, upgrade, purge ou mutacao de driver foi executada pelo
Codex no host. Ausencia de drivers adicionais e resultado valido.

## Artefato e instalacao limpa

No diretorio do pacote/checksum:

```bash
sha256sum --check SHA256SUMS
dpkg-deb -I ./mainuan-gestao-drivers_1.0_all.deb
dpkg-deb -c ./mainuan-gestao-drivers_1.0_all.deb
ubuntu-drivers devices
dpkg-query -W -f='${binary:Package} ${db:Status-Status} ${Version}\n' '*nvidia*' '*broadcom*' '*microcode*'
sudo apt install ./mainuan-gestao-drivers_1.0_all.deb
dpkg -s mainuan-gestao-drivers
dpkg -L mainuan-gestao-drivers
command -v mainuan-gestao-drivers
command -v mainuan-gestao-drivers-gtk-legacy || true
mainuan-gestao-drivers --version
mainuan-gestao-drivers
mainuan-gestao-drivers test
```

Consultas com globs podem retornar status nao zero se nenhum pacote existir.
Esperado: versao 1.0, Architecture all, um launcher Qt, icone oficial e nenhum
GTK/XApp/helper/sudoers instalado. Abrir pelo menu e pelo Mainuan Welcome sem
argumentos adicionais. Confirmar loading, deteccao, estado vazio correto e
fechamento. Testar todos os cenarios ficticios e preview sem tocar em drivers.

Revisar teclado (Tab/Shift+Tab/Space/Enter/Esc), textos pt_BR, janela pequena,
scroll e escala 100/125/150/200% no Plasma/Wayland. Nao forcar X11.
Conferir Sobre e diagnostico: 1.0, dados tecnicos sem senhas/chaves privadas.

Para pacotes realmente detectados, consultar somente leitura:

```bash
apt-cache policy NOME_DO_PACOTE_DETECTADO
```

Comparar candidate/origem/recommended. Nao adicionar PPAs, executar upgrade da
pilha grafica ou escolher versao numericamente maior para fabricar um teste.
Secure Boot/DKMS/MOK reais somente com hardware/configuracao adequados; nunca
enrollment, geracao de chave ou modprobe para validar este artefato.

## Upgrades diretos

Repetir separadamente a partir de snapshots com cada versao instalada:
`0.4`, `0.5`, `0.6` e `1.0~rc1`. Nao confundir quatro trajetos com um so teste.

```bash
dpkg -s mainuan-gestao-drivers
dpkg-query -W -f='${Conffiles}\n' mainuan-gestao-drivers
ls -l /etc/sudoers.d/
sudo apt install ./mainuan-gestao-drivers_1.0_all.deb
dpkg-query -W -f='${Version}\n' mainuan-gestao-drivers
test ! -e /etc/sudoers.d/mainuan-gestao-drivers-gtk-legacy
test ! -e /usr/bin/mainuan-gestao-drivers-gtk-legacy
test ! -e /usr/lib/mainuan/mainuan-gestao-drivers/gtk_legacy.py
test ! -e /usr/share/mainuan/mainuan-gestao-drivers/gtk-legacy.ui
test ! -e /usr/lib/mainuan/mainuan-gestao-drivers/load-broadcom-modules
dpkg -L mainuan-gestao-drivers
mainuan-gestao-drivers --version
mainuan-gestao-drivers
```

O `rm_conffile` com limite `0.5~` continua presente para o salto direto de 0.4.
Testar o arquivo original e, em outro snapshot, uma copia localmente modificada:
dpkg pode preservar a modificacao como `.dpkg-bak` inativo ate o purge. Nenhuma
regra ativa do projeto deve permanecer em sudoers.d. Nao apagar regras alheias.
As outras versoes ja removiam esse legado; a migracao continua no pacote final.

## Purge

Repetir apos instalacao limpa e apos os upgrades:

```bash
sudo apt purge mainuan-gestao-drivers
dpkg -s mainuan-gestao-drivers
command -v mainuan-gestao-drivers || true
test ! -e /usr/bin/mainuan-gestao-drivers
test ! -e /usr/lib/mainuan/mainuan-gestao-drivers
test ! -e /usr/share/applications/org.mainuan.GestaoDrivers.desktop
test ! -e /usr/share/icons/hicolor/scalable/apps/mainuan-gestao-drivers.svg
test ! -e /usr/share/icons/hicolor/48x48/apps/mainuan-gestao-drivers.png
test ! -e /etc/sudoers.d/mainuan-gestao-drivers-gtk-legacy
test ! -e /etc/sudoers.d/mainuan-gestao-drivers-gtk-legacy.dpkg-bak
```

`dpkg -s` deve informar ausencia do pacote depois do purge. Nao executar
autoremove: dependencias do sistema nao sao alvo destes scripts. Preferencias
normais em HOME nao devem ser apagadas; outros pacotes podem compartilhar
diretorios em /usr/share/locale, /usr/share/man e /usr/share/icons.

## PackageKit/PolicyKit opcional, com mutacao autorizada apenas na VM

O probe manual e ferramenta do checkout, nao e instalado pelo .deb:

```bash
python3 tests/manual/packagekit_mutation_probe.py install 2>&1 | tee packagekit-cancel.log
python3 tests/manual/packagekit_mutation_probe.py full 2>&1 | tee packagekit-mutation.log
```

Na primeira execucao, confirmar o prompt e cancelar PolicyKit; hello deve
permanecer ausente. Na segunda, autorizar instalacao, verificar o pacote e
confirmar remocao no MESMO processo/prompt. O probe recusa root, hello ja
instalado e remocao sem propriedade da instalacao na execucao atual. Nao usar
outra execucao `remove` para apagar um pacote preexistente. Se a sessao terminar
com hello instalado, a contingencia manual autorizada e `sudo apt remove hello`.
Esse teste nao substitui validacao de hardware nem deve instalar driver falso.
